Application Workflow

1 Authentication Phase: Users verify identity via Phone/Email OTP or Google SSO (OAuth2). Profile synchronization ensures persistence.

2 Discovery Phase: Natural language processing (Vocal/Text) for destination intent. Analyzes "Vibe," "Cuisine," and "Safety."

3 MCP Fetch Stage: Real-time parallel queries to IRCTC (Trains), Flight APIs, and Regional Transport providers.

4 AI Generation Loop: Trip Builder constructs 3 optimized packages based on real-time availability and user budget constraints.
